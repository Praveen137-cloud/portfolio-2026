## 🚀 Quick Start (Local Development)

### 1. View directly in browser
Simply double-click `index.html` or open it with any web browser (Chrome, Edge, Safari, Firefox).

### 2. Run local development server
You can start the built-in zero-dependency preview server:

```bash
# Using Node.js
node serve.js
# Or with npm
npm start
```

Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Deploying to Vercel, Netlify, or GitHub Pages

### Deploy to Vercel (Recommended)
1. Push this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial portfolio commit"
   git branch -M main
   git remote add origin https://github.com/Praveen137-cloud/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com), click **Add New Project**, import your `portfolio` repository, and click **Deploy**. Vercel will immediately serve it with global edge CDN and automated HTTPS!

### Deploy to GitHub Pages
1. In your GitHub repository, go to **Settings > Pages**.
2. Under **Build and deployment > Branch**, select `main` and `/ (root)`.
3. Click **Save**. Your site will be published at `https://Praveen137-cloud.github.io/portfolio/`.
